# AUX annotation audit

This audit separates exact lexical plausibility from human contextual validity. `aux_inventory.csv` is exhaustive. `aux_context_sample_for_blind_review.csv` is a deterministic, context-rich sample. Two independently randomized annotation packets and the full protocol are in `human_annotation/` and `HUMAN_ANNOTATION_PROTOCOL.md`. The automatic class must remain hidden until independent annotation and adjudication are frozen.
